# Kanhaiya Varnwal — Portfolio

Modern Vite + React + Tailwind CSS + Framer Motion developer portfolio.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## Replace placeholders

Search the project for:

- `YOUR_GITHUB_URL`
- `YOUR_LINKEDIN_URL`
- `YOUR_EMAIL`
- `YOUR_ECOMMERCE_GITHUB_URL`
- `YOUR_ECOMMERCE_LIVE_URL`
- `YOUR_EDTECH_GITHUB_URL`
- `YOUR_EDTECH_LIVE_URL`

The contact form is intentionally a frontend demo and should be connected to your API/email service before production.
